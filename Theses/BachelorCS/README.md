# MrNavi

MrNavi is a cross-platform mobile application for indoor navigation in buildings. The project was originally developed as a bachelor's thesis in Computer Science at Poznań University of Technology and has since continued as an actively developed mobile product.

The source code is not included in this public coursework repository, because the application has moved beyond the original thesis version and is maintained as a separate product. The current app can be downloaded from the official stores:

- [Google Play](https://play.google.com/store/apps/details?id=pl.mrreceipt.mrnavi)
- [App Store](https://apps.apple.com/td/app/mrnavi/id6738663932)
